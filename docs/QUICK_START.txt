1. APP STARTEN
   Start.bat (Doppelklick) oder:
   .\venv312\Scripts\python.exe main.py
   -> GUI oeffnet sich im Panel LIBRARY

2. EINEN ORDNER WAEHLEN
   Ordner in das Drop-Feld ziehen oder [Select Music Folder] klicken
   -> App durchsucht auch Unterordner nach WAV / AIFF / MP3 / FLAC

3. STRATEGIE WAEHLEN
   Dropdown STRATEGY, Standard: Harmonic Flow

   Genau 8 Strategien (hpg_core/playlist.py, STRATEGIES):
   - Harmonic Flow   -> Camelot-Kompatibilitaet mit Look-Ahead und Backtracking
   - Warm-Up         -> BPM aufsteigend
   - Cool-Down       -> BPM absteigend
   - Peak-Time       -> einstellbare Peak-Position + Harmonic Smoothing
   - Energy Wave     -> abwechselnd hohe/niedrige Energie
   - Genre Flow      -> Genre-Cluster mit weichen Uebergaengen
   - Consistent      -> minimale BPM-/Energie-Spruenge, harmonisch bevorzugt
   - Context Flow    -> Set-Phasen-Zielenergie, Trend, Genre-Fatigue

   Alte Namen bleiben nur ueber STRATEGY_ALIASES gueltig, genau drei:
   "Harmonic Flow Enhanced", "Peak-Time Enhanced", "Emotional Journey".
   Nicht mehr vorhanden: Surprise me, Danceability Peak, BPM Progression,
   Genre Explorer, Smooth Crossfade, Harmonic Consistent.

4. EINSTELLUNGEN (Optional)
   BPM TOLERANCE: Slider 1-2, Standard +/-2
   -> Liegt ein Nachbarpaar ausserhalb der eingestellten Toleranz, bleibt der
      Track in der Playlist. Die Kante erscheint als UNGEPLANT (Score 0) und
      wird weder vorgespielt noch gerendert.
   ADVANCED PARAMETERS (rechte Spalte): es bleiben nur die Regler aktiv,
   die die gewaehlte Strategie wirklich nutzt
   (hpg_core/playlist.py, SUPPORTED_STRATEGY_PARAMETERS)

5. GENERIEREN
   [GENERATE PLAYLIST] oder Ctrl+G
   -> Analyse laeuft mehrkernig; die Dauer haengt an Trackzahl und Cache
   -> Ergebnis ist EINE Playlist fuer die gewaehlte Strategie

6. ANSEHEN UND ANHOEREN
   Panels per Ctrl+1 bis Ctrl+5: LIBRARY, PLAYLIST, MIX TIPS, TIMELINE, QUALITY
   [PREVIEW TRANSITIONS] rendert die Uebergaenge zum Anhoeren (Space = Play/Pause)

7. EXPORTIEREN
   [EXPORT PLAYLIST] oder Ctrl+E -> Format waehlen:
   - M3U8 (Standard Playlist, Universal)
   - Rekordbox XML (Pioneer DJ Software)

================================================================================
VERSTEHEN DER PLAYLIST-GENERIERUNG
================================================================================

DER ALGORITHMUS FRAGT SICH:

"Welcher Track passt als NAECHSTER?"

Kriterien, auf die geachtet wird:

+ HARMONIE (Camelot-Rad, Mapping in hpg_core/models.py)
  8A (A Minor)  -> 9A (E Minor)   ok  (Nachbar im Camelot Wheel)
  8A (A Minor)  -> 8B (C Major)   ok  (Dur/Moll-Wechsel derselben Zahl)
  8A (A Minor)  -> 3B (C# Major)  nein (zu weit weg)

+ BPM (TEMPO)
  128 BPM -> 130 BPM  ok   (nur 2 BPM Unterschied)
  128 BPM -> 170 BPM  nein (grosser Sprung, schwer zu mixen)
  Half/Double-Time wird erkannt und toleriert

+ ENERGIE
  Sollte zur gewaehlten Strategie passen:
  - Peak-Time:     Aufbau, Peak an einstellbarer Position, Abbau
  - Harmonic Flow: aehnlich halten
  - Energy Wave:   Auf-Ab-Auf-Ab Muster

+ GENRE
  Die App kennt 9 kanonische, rein elektronische Genres
  (hpg_core/genres.py, CANONICAL_GENRES): Psytrance, Tech House,
  Progressive, Melodic Techno, Techno, Deep House, Trance,
  Drum & Bass, Minimal.
  Tech House -> Deep House  ok
  Techno     -> Drum & Bass nein (zu unterschiedlich)

+ STRUKTUR
  Mix-Out im Outro von A trifft Mix-In im Intro von B, phrasen-quantisiert

================================================================================
DATEIEN VERSTEHEN
================================================================================

main.py                        -> PyQt6-GUI, alle QThread-Worker.
                                  Es gibt KEINEN GUI/-Ordner, kein ui/-Paket
                                  und kein theme.py im Wurzelverzeichnis.

hpg_core/
  playlist.py                  -> alle 8 Strategien + Scoring (STRATEGIES)
  analysis.py                  -> Audio-Analyse mit librosa (analyze_track)
  downbeat.py                  -> Downbeat- und Phrasen-Anker
  dj_brain.py                  -> genre-spezifische Mixpoints, DJ-Empfehlungen
  parallel_analyzer.py         -> ProcessPoolExecutor, automatisch bis 4 Worker
                                  (config.PARALLEL_AUTO_MAX_WORKERS)
  genre_classifier.py          -> regelbasierte Genre-Erkennung (kein ML)
  structure_analyzer.py        -> Intro/Breakdown/Drop/Outro
  transition_renderer.py       -> Uebergangs-Preview (Crossfade, EQ, Limiter)
  caching.py                   -> SQLite-Cache, CACHE_VERSION 44
  genres.py                    -> 9 kanonische Genres (Single Source of Truth)
  theme.py                     -> Farben und Styles der GUI
  models.py                    -> Track-Dataclass, Camelot-Map
  exporters/m3u8_exporter.py           -> Playlist-Export (Standard)
  exporters/rekordbox_xml_exporter.py  -> Pioneer DJ Format

tests/
  conftest.py                  -> Gemeinsame Fixtures & Konfiguration
  performance_fixtures.py      -> Cached Track-Fixtures (schnelle Tests)
  test_playlist_strategies.py  -> Strategie-Tests
  test_playlist_quality.py     -> Qualitaetsmetriken
  test_analysis.py             -> Audio-Analyse Tests
  test_exporters.py            -> Export-Format Tests
  (eine Datei tests/test_playlist.py gibt es nicht)

Der Laufzeit-Cache liegt ausserhalb des Repos:
  %LOCALAPPDATA%\HPG\hpg_cache_v44.db
  (ueberschreibbar mit HPG_CACHE_DIR bzw. HPG_CACHE_FILE)

================================================================================
HAEUFIGE FRAGEN
================================================================================

F: Warum ist meine Playlist nicht gut?
A: 1) Andere Strategie versuchen
   2) BPM-Toleranz anpassen
   3) Genre kann inkonsistent sein -> Genre Flow probieren
   4) Energie-Kurve passt nicht -> Peak-Time oder Energy Wave

F: Warum sind diese Tracks zusammen?
A: Siehe docs/PLAYLIST_ALGORITHMEN_ERKLAERUNG.md und das Panel MIX TIPS

F: Kann ich die Gewichte anpassen?
A: Ja. Alle fuenf sichtbaren Regler fuer Groove, Bassdruck, Klangfarbe,
   Stimmung und Lautheit gewichten ausschliesslich Mixpunkt-Kandidaten.
   Harmonik, BPM, Energie, Genre und Struktur stammen aus
   Hoertestpraeferenzen oder den Toleranzvorgaben. Gewichtsaenderungen brauchen keine Neuanalyse;
   geaenderte Analyse-Ausgaben dagegen schon einen CACHE_VERSION-Bump.

F: Warum ist die Audio-Analyse so langsam?
A: librosa ist gruendlich (BPM, Key, Struktur, Energie ...). Der optionale
   Rekordbox-Import nutzt vorhandene Metadaten und ist deutlich schneller.
   Ergebnisse werden gecacht; der zweite Lauf ueber denselben Ordner ist schnell.

F: Kann ich die App fuer ein Festival nutzen?
A: Ja. Playlist generieren und als M3U8 oder Rekordbox XML exportieren,
   dann in den DJ-Player laden.

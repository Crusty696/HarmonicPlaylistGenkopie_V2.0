(MixCandidate mit lokalen Messwerten: Struktur/Neuheit/Tragfaehigkeit, Rhythmus
inkl. syncopation+percussive_ratio, Bass inkl. absolutem RMS+Kick-Status,
Harmonie lokal+key_confidence, Klangfarbe inkl. Mitten/Hoehen, Energie+LUFS

stillschweigend vereinfacht wurden. Er prueft Vollstaendigkeit selbst.

- Jede Behauptung ueber Daten/Code vor Gebrauch nachmessen; keine Annahme als
  Fakt darstellen.
